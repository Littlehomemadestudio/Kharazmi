# فلوچارت اصلی برنامه RASK!

## توضیحات
این فلوچارت جریان کلی اجرای برنامه RASK! را از لحظه اجرا تا نمایش داشبورد اصلی و ناوبری بین تب‌های مختلف نشان می‌دهد. برنامه یک اپلیکیشن دسکتاپ مبتنی بر PySide6 است که شامل ۶ بخش اصلی می‌باشد.

```mermaid
flowchart TD
    START([شروع برنامه]) --> SPLASH[نمایش صفحه Splash]
    SPLASH --> INIT_CHECK{بررسی اولیه}

    INIT_CHECK -->|بررسی وابستگی‌ها| DEP_CHECK[بررسی نصب کتابخانه‌ها]
    INIT_CHECK -->|بررسی تنظیمات| CONFIG_LOAD[بارگذاری تنظیمات از QSettings]
    INIT_CHECK -->|بررسی پایگاه داده| DB_CHECK{پایگاه داده موجود؟}

    DEP_CHECK -->|خطا| ERR_DEP[نمایش خطای وابستگی]
    ERR_DEP --> EXIT([خروج])

    DB_CHECK -->|خیر| DB_CREATE[ایجاد پایگاه داده SQLite]
    DB_CHECK -->|بله| DB_MIGRATE[بررسی و اجرای Migrations]

    DB_SEED --> THEME_LOAD
    DB_MIGRATE --> THEME_LOAD

    CONFIG_LOAD --> THEME_LOAD[بارگذاری تم و پالت رنگ]
    THEME_LOAD --> FONT_LOAD[بارگذاری فونت‌های فارسی Vazirmatn]
    FONT_LOAD --> ICON_LOAD[بارگذاری آیکون‌های Material Symbols]

    ICON_LOAD --> MAIN_WIN[ساخت MainWindow]
    MAIN_WIN --> SIDEBAR[ساخت SideBar ناوبری]
    SIDEBAR --> STACKED[ساخت QStackedWidget]
    STACKED --> TABS[ساخت ۶ تب اصلی]

    TABS --> TAB1[تب ۱: تقویم شمسی]
    TABS --> TAB2[تب ۲: مدیریت پروژه]
    TABS --> TAB3[تب ۳: هوش مصنوعی]
    TABS --> TAB4[تب ۴: یادداشت‌ها]
    TABS --> TAB5[تب ۵: ژورنال]
    TABS --> TAB6[تب ۶: تنظیمات]

    TAB1 --> DASHBOARD
    TAB2 --> DASHBOARD
    TAB3 --> DASHBOARD
    TAB4 --> DASHBOARD
    TAB5 --> DASHBOARD
    TAB6 --> DASHBOARD

    DASHBOARD[نمایش داشبورد اصلی]
    DASHBOARD --> WIDGETS[بارگذاری ویجت‌های داشبورد]
    WIDGETS --> W1[ویجت تقویم ماهانه]
    WIDGETS --> W2[ویجت پروژه‌های فعال]

    W1 --> READY
    W2 --> READY
    W3 --> READY
    W4 --> READY

    READY[برنامه آماده استفاده] --> NAV{ناوبری کاربر}

    NAV -->|کلیک تقویم| CAL_TAB[فعال‌سازی تب تقویم]
    NAV -->|کلیک پروژه| PROJ_TAB[فعال‌سازی تب پروژه]
    NAV -->|کلیک هوش مصنوعی| AI_TAB[فعال‌سازی تب AI]
    NAV -->|کلیک یادداشت| NOTE_TAB[فعال‌سازی تب یادداشت]
    NAV -->|کلیک ژورنال| JOURNAL_TAB[فعال‌سازی تب ژورنال]
    NAV -->|کلیک تنظیمات| SETTINGS_TAB[فعال‌سازی تب تنظیمات]

    CAL_TAB --> CAL_INIT[مقداردهی اولیه تقویم]
    PROJ_TAB --> PROJ_INIT[مقداردهی اولیه پروژه]
    AI_TAB --> AI_INIT[مقداردهی اولیه AI Chat]
    NOTE_TAB --> NOTE_INIT[مقداردهی اولیه یادداشت]
    JOURNAL_TAB --> JOURNAL_INIT[مقداردهی اولیه ژورنال]
    SETTINGS_TAB --> SETTINGS_INIT[مقداردهی اولیه تنظیمات]

    CAL_INIT --> INTERACTIVE[حالت تعاملی]

    INTERACTIVE --> USER_ACTION{عمل کاربر}

    USER_ACTION -->|تغییر تب| NAV
    USER_ACTION -->|بستن برنامه| CLOSE_CHECK{ذخیره تغییرات؟}

    UNDO_PUSH --> SAVE_AUTO[ذخیره خودکار]
    SAVE_AUTO --> INTERACTIVE

    CLOSE_CHECK -->|بله| SAVE_ALL[ذخیره تمام تغییرات]
    CLOSE_CHECK -->|خیر| FORCE_CLOSE

    FORCE_CLOSE --> CLEANUP
    CLEANUP --> EXIT2([پایان برنامه])
```

## توضیح مراحل اصلی

1. **مرحله راه‌اندازی (Startup)**: برنامه با صفحه Splash شروع شده و وابستگی‌ها، تنظیمات و پایگاه داده را بررسی می‌کند.
2. **مرحله مقداردهی (Initialization)**: تم، فونت فارسی و آیکون‌ها بارگذاری می‌شوند و پنجره اصلی ساخته می‌شود.
3. **مرحله داشبورد (Dashboard)**: ویجت‌های خلاصه اطلاعات نمایش داده می‌شوند.
4. **مرحله تعاملی (Interactive)**: کاربر بین تب‌ها ناوبری می‌کند و هر عمل در Undo Stack ثبت می‌شود.
5. **مرحله بستن (Shutdown)**: تغییرات ذخیره و منابع آزاد می‌شوند.
