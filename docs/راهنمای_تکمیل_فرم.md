### ۵. مراحل ثبت نام در سامانه

1. **ثبت نام**: از طریق سامانه `https://my.medu.ir` با نام کاربری و رمز ورود
2. **انتخاب همگروهی**: اگر تیم ۲ نفره است، همگروهی را اضافه کنید
3. **بارگذاری فایل‌ها**: مستندات، سورس کد، خروجی، و فیلم را در سامانه بارگذاری کنید
4. **لینک اشتراک‌گذاری**: فایل‌های زیپ‌شده را در `picofile.com` یا `bayan.ir` بارگذاری کنید و لینک را در فایل Word یا Notepad قرار دهید

### ۸. سوالاتی که داوران ممکن است بپرسند

| سوال | پاسخ پیشنهادی |
|---|---|
| چرا پایتون انتخاب کردید؟ | زبان ساده و خوانا، کتابخانه‌های غنی، مناسب برای یادگیری و توسعه سریع |
| معماری DDD چیست؟ | Domain-Driven Design: طراحی نرم‌افزار بر اساس مدل دامنه، لایه‌ای با وابستگی یک‌طرفه |
| الگوریتم CPM چطور کار می‌کند؟ | مسیر بحرانی: Forward Pass (ES/EF) → Backward Pass (LS/LF) → Slack = LS - ES |
| شبیه‌سازی مونت‌کارلو چیست؟ | تولید تصادفی N سناریو با توزیع احتمال، محاسبه احتمال اتمام پروژه |
| چرا تقویم شمسی مهم است؟ | تقویم رسمی ایران شمسی است، تعطیلات و مناسبت‌ها بر اساس شمسی |
| هوش مصنوعی چطور استفاده شده؟ | GLM-4.5-flash برای برنامه‌ریزی مسیر و دستیار تقویم، با streaming |
| چرا SQLite؟ | سبک، بدون نیاز به سرور، مناسب اپلیکیشن دسکتاپ، پشتیبانی کامل SQL |
| سیستم Undo/Redo چطور کار می‌کند؟ | الگوی Command: هر عملیات یک Command است، UndoStack با حداکثر ۲۰۰ عملیات |
| تفاوت با نمونه‌های مشابه؟ | اولین اپ دسکتاپ با تقویم شمسی بومی + AI + ۵ الگوریتم زمان‌بندی |
| امنیت چطور تضمین می‌شود؟ | ذخیره‌سازی محلی، بدون ارسال داده به سرور (به جز AI)، اعتبارسنجی ورودی |
