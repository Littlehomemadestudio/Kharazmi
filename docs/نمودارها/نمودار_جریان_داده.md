# نمودار جریان داده RASK! — Data Flow Diagram

## توضیحات

این نمودار نحوه جریان داده در سیستم RASK! را نشان می‌دهد. داده‌ها از ورودی کاربر آغاز شده، از طریق لایه‌های مختلف سیستم عبور می‌کنند و در نهایت در پایگاه داده SQLite ذخیره یا از API هوش مصنوعی دریافت می‌شوند. دو مسیر اصلی داده وجود دارد:

1. **مسیر مدیریت پروژه**: کاربر → UI → Services → Commands → Core Domain → Persistence
2. **مسیر هوش مصنوعی**: کاربر → UI → AIService → GLM API (z.ai)

---

## نمودار کلی جریان داده

```mermaid
graph TB
    %% منابع داده
    User(["👤 کاربر"])
    GLM[["🌐 GLM API<br/>api.z.ai<br/>مدل: glm-4.5-flash / glm-4.5"]]
    SQLite[("🗄️ SQLite<br/>rask.sqlite3<br/>calendar.sqlite3")]
    FileSystem[("📁 فایل سیستم<br/>~/.rask/")]

    %% لایه رابط کاربری
    subgraph UI["رابط کاربری — PySide6"]
        MainWindow["RaskMainWindow"]
        GraphView["NodeGraphView<br/>نمای گراف وظایف"]
        GanttView["GanttView<br/>نمای گانت"]
        KanbanView["KanbanView<br/>نمای کانبان"]
        CalView["CalendarView<br/>نمای تقویم"]
        AIView["AIPlannerView<br/>نمای برنامه‌ریز AI"]
        Dashboard["DashboardView<br/>داشبورد"]
    end

    %% لایه سرویس
    subgraph Services["لایه سرویس‌ها"]
        TaskSvc["TaskService"]
        SchedSvc["SchedulingService"]
        AdvisorSvc["Advisor"]
        ExportSvc["ExportService"]
    end

    %% لایه فرمان
    subgraph CmdLayer["لایه فرمان‌ها"]
        UndoStack["UndoStack"]
        Commands["فرمان‌ها<br/>Create · Delete · Update<br/>Move · ChangeStatus<br/>AddDep · RemoveDep"]
    end

    %% لایه الگوریتم
    subgraph AlgoLayer["لایه الگوریتم‌ها"]
        CPM["CPM<br/>مسیر بحرانی"]
        PERT["PERT<br/>تخمین سه‌نقطه‌ای"]
        MC["Monte Carlo<br/>شبیه‌سازی"]
        RL["Resource Leveling<br/>تسطیح منابع"]
    end

    %% لایه هسته
    subgraph Core["هسته دامنه"]
        Project["Project<br/>گراف وظایف"]
        CalendarStore["CalendarStore<br/>مخزن تقویم"]
    end

    %% لایه ماندگاری
    subgraph Persist["لایه ماندگاری"]
        SQLiteRepo["SQLiteRepository"]
        CalRepo["CalendarRepository"]
        JournalStore["JournalStore"]
    end

    %% زیرسیستم AI
    subgraph AISub["زیرسیستم هوش مصنوعی"]
        AIService["AIService<br/>مدیریت درخواست‌ها"]
        NLParser["Natural Language Parser<br/>پردازش زبان طبیعی"]
    end

    %% جریان داده اصلی — مسیر مدیریت پروژه
    User -->|"رویداد ماوس/کیبورد"| MainWindow
    MainWindow -->|"درخواست عملیات"| GraphView & GanttView & KanbanView & Dashboard
    GraphView & GanttView & KanbanView -->|"فراخوانی"| TaskSvc
    Dashboard -->|"فراخوانی"| SchedSvc

    TaskSvc -->|"execute(cmd)"| Commands
    Commands -->|"push()"| UndoStack
    Commands -->|"تغییر داده"| Project
    TaskSvc -->|"recalculate()"| SchedSvc
    SchedSvc -->|"اجرای الگوریتم"| CPM & PERT & MC & RL
    CPM & PERT & MC & RL -->|"نوشتن نتایج<br/>early_start, late_start, slack"| Project

    %% جریان داده — مسیر تقویم
    CalView -->|"درخواست"| CalendarStore
    CalendarStore -->|"رویدادهای تقویم"| CalView

    %% جریان داده — مسیر AI
    AIView -->|"درخواست برنامه‌ریزی"| AIService
    AIService -->|"POST /chat/completions"| GLM
    GLM -->|"JSON Response<br/>Route · Steps · Questions"| AIService
    AIService -->|"مسیر پیشنهادی"| AIView
    User -->|"متن زبان طبیعی"| NLParser
    NLParser -->|"رویداد تجزیه‌شده"| CalendarStore

    %% جریان داده — ماندگاری
    Project -->|"save_snapshot()"| SQLiteRepo
    CalendarStore -->|"save()"| CalRepo
    SQLiteRepo -->|"SQL INSERT/SELECT"| SQLite
    CalRepo -->|"SQL INSERT/SELECT"| SQLite
    SQLiteRepo -->|"load_latest()"| Project
    CalRepo -->|"load_latest()"| CalendarStore
    JournalStore -->|"خواندن/نوشتن"| FileSystem

    %% جریان داده — مشاوره
    AdvisorSvc -->|"تحلیل"| Project
    AdvisorSvc -->|"پیشنهاد"| User

    %% سبک‌ها
    style User fill:#2C3E50,stroke:#1A252F,color:#fff
    style GLM fill:#8E44AD,stroke:#6C3483,color:#fff
    style SQLite fill:#2C3E50,stroke:#1A252F,color:#fff
```

## خلاصه جریان‌های داده

| جریان | ورودی | خروجی | ذخیره‌سازی |
|-------|--------|--------|-----------|
| مدیریت وظایف | عملیات کاربر | بروزرسانی Project | SQLite snapshot |
| زمان‌بندی | داده‌های پروژه | نتایج CPM/PERT/MC | درون‌حافظه‌ای (روی Task) |
| هوش مصنوعی | اهداف + خلاصه پروژه | مسیر پیشنهادی | درون‌حافظه‌ای |
| تقویم | رویداد/ناوبری | بروزرسانی CalendarStore | SQLite snapshot |
| Undo/Redo | فرمان‌های اجرا‌شده | بازگشت به حالت قبلی | SQLite snapshot |
| خروجی | داده‌های پروژه | فایل CSV/JSON | فایل سیستم |
