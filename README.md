## 🌟 درباره RASK

RASK یک برنامه‌ریزی و مدیریت وظایف هوشمند است که با پایتون و PySide6 ساخته شده. این برنامه با استفاده از هوش مصنوعی و الگوریتم‌های پیشرفته، به شما کمک می‌کند تا پروژه‌های خود را به بهترین شکل مدیریت کنید.

### ویژگی‌های اصلی

- 📅 **تقویم شمسی** — تقویم کامل شمسی با نمایش ماه، هفته، روز و سال
- 🤖 **برنامه‌ریز هوشمند** — تولید مسیر عملیاتی با هوش مصنوعی GLM-4.5
- 📊 **نمودارهای تحلیلی** — نمایش گرافیکی مسیرها و پیشرفت پروژه
- 🧪 **شبیه‌سازی مونت‌کارلو** — تحلیل ریسک و پیش‌بینی زمان تکمیل
- 📖 **دفترچه روزانه** — تاریخچه تمام مسیرهای تولید شده توسط AI
- ✦ **مدیریت وظایف** — گراف وظایف با روش مسیر بحرانی (CPM) و PERT

### الگوریتم‌های زمان‌بندی

| الگوریتم | توضیح |
|----------|-------|
| مسیر بحرانی (CPM) | محاسبه طولانی‌ترین مسیر پروژه |
| PERT | تخمین زمان با سه سناریو |
| مونت‌کارلو | شبیه‌سازی آماری ریسک |
| مرتب‌سازی توپولوژیک | ترتیب اجرای وظایف |
| تراز منابع | بهینه‌سازی تخصیص منابع |

## 🚀 نصب و اجرا

```bash
# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرای برنامه
python main.py
```

## 🛠️ تکنولوژی‌ها

- **زبان**: Python 3.11+
- **رابط کاربری**: PySide6 (Qt for Python)
- **هوش مصنوعی**: GLM-4.5-flash (ZhipuAI)
- **پایگاه داده**: SQLite
- **تقویم**: شمسی/جلالی (تبدیل دوطرفه)

## 📂 ساختار پروژه

```
kharazmi/
├── core/           # مدل‌های دامنه (وظیفه، پروژه، وابستگی)
├── algorithms/     # الگوریتم‌های زمان‌بندی (CPM, PERT, Monte Carlo)
├── calendar/       # تقویم شمسی و مدیریت رویدادها
├── ai/             # سرویس هوش مصنوعی و دفترچه روزانه
├── persistence/    # ذخیره‌سازی SQLite
├── commands/       # سیستم دستور و برگشت‌پذیری
├── services/       # سرویس‌های برنامه‌ریزی و صادرکردن
└── ui/             # رابط کاربری و ویجت‌ها
```
