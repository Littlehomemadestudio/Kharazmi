## 🌟 معرفی پروژه

**RASK!** یک برنامه‌ریزی و مدیریت وظایف هوشمند دسکتاپ است که با پایتون و فریم‌ورک PySide6 (Qt for Python) ساخته شده و ویژه دانش‌آموزان و جوانان ایرانی طراحی گردیده است. این نرم‌افزار با ترکیب تقویم شمسی بومی، الگوریتم‌های پیشرفته زمان‌بندی پروژه و دستیار هوش مصنوعی، یک پلتفرم یکپارچه برای مدیریت زمان و پروژه ارائه می‌دهد.

دانش‌آموزان ایرانی در مدیریت زمان و برنامه‌ریزی تحصیلی با چالش‌های چندوجهی روبه‌رو هستند: ابزارهای موجود یا بر پایه تقویم میلادی هستند و پشتیبانی بومی‌ای از تقویم شمسی ندارند، یا فاقد الگوریتم‌های حرفه‌ای زمان‌بندی مانند CPM و شبیه‌سازی مونت‌کارلو هستند، و هیچ‌کدام از هوش مصنوعی برای برنامه‌ریزی هوشمند استفاده نمی‌کنند. RASK! این خلأ را با ارائه یک ابزار جامع، بومی‌سازی‌شده و هوشمند پر می‌کند.

این نرم‌افزار با معماری **طراحی دامنه‌محور (DDD)** توسعه یافته، از ۵ الگوریتم زمان‌بندی پیشرفته بهره می‌برد، و با دستیار هوش مصنوعی GLM-4.5، قابلیت برنامه‌ریزی هوشمند و پیشنهاد زمان‌بندی بهینه را فراهم می‌سازد. رابط کاربری حرفه‌ای با پالت رنگی طلایی-خاکستری، سیستم تم روشن/تیره و نوار عنوان شیشه‌ای، تجربه‌ای لذت‌بخش و کاربردی را ارائه می‌دهد.

## ✨ ویژگی‌های کلیدی

- 📅 **تقویم شمسی هوشمند** — تقویم کامل جلالی با نمای ماه، هفته، روز و سال؛ تبدیل دوطرفه شمسی-میلادی؛ تعطیلات رسمی و مناسبت‌های ملی؛ رویدادهای تکرارشونده؛ و پیشنهاد هوشمند رویداد توسط AI
- 📊 **مدیریت پروژه حرفه‌ای** — گراف وظایف تعاملی با وابستگی‌های چهارگانه (FS, SS, FF, SF)؛ نمودار گانت؛ نمودار شبکه‌ای؛ اولویت‌بندی و پیشرفت وظایف؛ پنل بازرسی اختصاصی
- 🧮 **۵ الگوریتم زمان‌بندی** — مسیر بحرانی (CPM)، تخمین سه‌نقطه‌ای (PERT)، شبیه‌سازی مونت‌کارلو، مرتب‌سازی توپولوژیک (الگوریتم کان)، و متوازن‌سازی منابع (Resource Leveling)
- 🤖 **دستیار هوش مصنوعی** — برنامه‌ریزی هوشمند مسیر پروژه با مدل GLM-4.5-flash؛ چت تعاملی؛ پرسش‌های چندگزینه‌ای؛ پیشنهاد زمان‌بندی بهینه؛ و حباب‌های بینش (Insight Bubbles)
- 📖 **یادداشت‌روزانه (ژورنال)** — ثبت و بازبینی تمام مسیرهای تولیدشده توسط AI؛ تاریخچه کامل برنامه‌ریزی‌ها؛ جستجو و فیلتر بر اساس تاریخ شمسی
- 🎨 **رابط کاربری حرفه‌ای** — پالت رنگی طلایی-خاکستری؛ تم روشن/تیره؛ نوار عنوان شیشه‌ای (Glass Title Bar)؛ اسپلش‌اسکرین حرفه‌ای؛ تور معرفی اولیه؛ پالت فرمان (Command Palette)
- 🔄 **سیستم Undo/Redo** — الگوی Command حرفه‌ای با پشتیبانی حداکثر ۲۰۰ عملیات برگشت‌پذیر؛ تاریخچه دستورات؛ میانبرهای Ctrl+Z / Ctrl+Y
- 💾 **ذخیره‌سازی خودکار** — ذخیره‌سازی خودکار هر ۶۰ ثانیه؛ پایگاه داده SQLite با الگوی Repository؛ اسنپ‌شات و تاریخچه نسخه‌ها

## 🏗️ معماری نرم‌افزار

RASK! بر اساس الگوی **طراحی راهنمایی‌شده با دامنه (Domain-Driven Design)** معماری‌سازی شده است. سیستم از ۶ لایه مجزا تشکیل شده که هر لایه فقط به لایه‌های زیرین خود وابسته است. این جداسازی تضمین می‌کند که منطق کسب‌وکار مستقل از زیرساخت فنی بماند و قابلیت آزمون‌پذیری و نگهداری کد افزایش یابد.

```
┌─────────────────────────────────────────────────────┐
│              🖥️ لایه رابط کاربری (UI)                │
│    MainWindow · Views · Calendar UI · Dialogs        │
│    Widgets · Theme · Icons                           │
├─────────────────────────────────────────────────────┤
│              ⚙️ لایه سرویس‌ها (Services)              │
│    TaskService · SchedulingService · ExportService   │
│    Advisor · RouteExport                             │
├─────────────────────────────────────────────────────┤
│              🔄 لایه فرمان‌ها (Commands)              │
│    UndoStack · CreateTask · DeleteTask · UpdateTask  │
│    MoveTask · ChangeStatus · Add/RemoveDependency    │
├─────────────────────────────────────────────────────┤
│              🧮 لایه الگوریتم‌ها (Algorithms)         │
│    CPM · PERT · Monte Carlo · Resource Leveling     │
│    Topological Sort · Cycle Detection                │
├─────────────────────────────────────────────────────┤
│              💎 لایه هسته دامنه (Core Domain)         │
│    Project · Task · Dependency · Duration            │
│    Value Objects · Domain Events · Enums             │
│    ShamsiDate · Calendar System                      │
├─────────────────────────────────────────────────────┤
│              💾 لایه ماندگاری (Persistence)           │
│    SQLiteRepository · CalendarRepository             │
│    Serializers · JSON Store                          │
└─────────────────────────────────────────────────────┘
```

### الگوهای طراحی به‌کاررفته

| الگو | کاربرد | ماژول |
|------|--------|-------|
| **Repository** | جداسازی لایه ذخیره‌سازی از منطق دامنه | `persistence` |
| **Command** | عملیات برگشت‌پذیر (Undo/Redo) | `commands` |
| **Observer** | رویدادهای دامنه و اطلاع‌رسانی تغییرات | `core.events` |
| **Service Layer** | هماهنگی عملیات و تراکنش‌های اپلیکیشن | `services` |
| **Value Object** | اشیاء تغییرناپذیر مانند Duration و TaskId | `core.value_objects` |
| **Aggregate Root** | ریشه تجمیعی Project به‌عنوان نقطه ورود گراف | `core.project` |

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

- **پایتون** نسخه ۳.۱۱ یا بالاتر
- **pip** (مدیر بسته پایتون)
- سیستم‌عامل **ویندوز**، **لینوکس** یا **macOS**

### مراحل نصب

```bash
# ۱. کلون کردن مخزن
git clone <repository-url>
cd kharazmi-source

# ۲. ایجاد محیط مجازی (پیشنهاد می‌شود)
python -m venv venv

# فعال‌سازی در ویندوز
venv\Scripts\activate

# فعال‌سازی در لینوکس/macOS
source venv/bin/activate

# ۳. نصب وابستگی‌ها
pip install -r requirements.txt

# ۴. اجرای برنامه
python main/main.py
```

## 🖥️ نماهای برنامه

RASK! از ۶ تب اصلی تشکیل شده که هر کدام قابلیت‌های تخصصی خود را دارند:

### 🏠 خانه (Dashboard)
نمای اصلی و داشبورد برنامه. نمایش تاریخ شمسی امروز، رویدادهای پیش‌رو، وضعیت پروژه‌های فعال، پیشنهادهای هوش مصنوعی و دسترسی سریع به بخش‌های مختلف برنامه.

### 📅 تقویم (Calendar)
تقویم شمسی تعاملی با چهار نمای ماه، هفته، روز و سال. امکان ایجاد و ویرایش رویدادها، تعریف رویدادهای تکرارشونده، مشاهده تعطیلات رسمی و مناسبت‌های ملی، و پیشنهاد هوشمند رویداد توسط AI.

### ✦ برنامه‌ریز و وظایف (Planner & Tasks)
فضای کاری یکپارچه شامل دستیار هوش مصنوعی و گراف وظایف. کاربر می‌تواند با AI چت کند، مسیر پروژه را برنامه‌ریزی نماید، وظایف و وابستگی‌ها را تعریف کرده و نمودار گantt و نمودار شبکه‌ای را مشاهده کند.

### 📊 نمودارها (Graphs)
نمایش گرافیکی پیشرفت پروژه‌ها، تحلیل مسیرهای بحرانی، نمودارهای آماری و مقایسه‌ای. امکان انتخاب مسیرهای برنامه‌ریزی شده و بررسی جزئیات آن‌ها.

### 🧪 شبیه‌سازی (Simulation)
اجراهای شبیه‌سازی مونت‌کارلو با نمایش نمودار توزیع احتمال، تحلیل ریسک، پیش‌بینی زمان اتمام پروژه و نمایش صدک‌های P10، P50، P90 و P95.

### 📖 یادداشت‌ها (Journal)
یادداشت‌روزانه (ژورنال) برای ثبت و بازبینی تمام مسیرهای تولیدشده توسط هوش مصنوعی. تاریخچه کامل برنامه‌ریزی‌ها با قابلیت جستجو و فیلتر بر اساس تاریخ شمسی.

## 🧮 الگوریتم‌ها

RASK! از ۵ الگوریتم زمان‌بندی پیشرفته بهره می‌برد:

### ۱. مسیر بحرانی (CPM — Critical Path Method)
محاسبه طولانی‌ترین مسیر پروژه و تعیین وظایف بحرانی. این الگوریتم با محاسبه زمان‌های آغاز زودهنگام (ES) و دیرهنگام (LS) برای هر وظیفه، شناور (Slack) هر وظیفه را تعیین کرده و مسیر بحرانی پروژه را شناسایی می‌کند. وظایف بحرانی شناور صفر دارند و هر تأخیر در آن‌ها مستقیماً زمان اتمام پروژه را به تأخیر می‌اندازد.

### ۲. تخمین سه‌نقطه‌ای (PERT — Program Evaluation and Review Technique)
تخمین زمان پروژه با سه سناریو خوش‌بینانه (Optimistic)، محتمل‌ترین (Most Likely) و بدبینانه (Pessimistic). فرمول PERT زمان مورد انتظار هر وظیفه را به‌صورت وزنی محاسبه می‌کند و با استفاده از توزیع نرمال، احتمال اتمام پروژه در هر زمان هدف را پیش‌بینی می‌نماید.

### ۳. شبیه‌سازی مونت‌کارلو (Monte Carlo Simulation)
تحلیل ریسک و پیش‌بینی زمان اتمام پروژه با شبیه‌سازی آماری هزاران سناریو. این الگوریتم با نمونه‌برداری تصادفی از توزیع‌های زمان هر وظیفه، نمودار توزیع احتمال زمان اتمام پروژه را تولید می‌کند و صدک‌های P10، P50، P90 و P95 را ارائه می‌دهد.

### ۴. مرتب‌سازی توپولوژیک (Topological Sort — Kahn's Algorithm)
تعیین ترتیب اجرای صحیح وظایف بر اساس وابستگی‌ها. الگوریتم کان با محاسبه درجه ورودی هر گره و پردازش صف، ترتیب خطی وظایف را تولید می‌کند. همچنین تشخیص دور در گراف وابستگی‌ها را فراهم می‌سازد.

### ۵. متوازن‌سازی منابع (Resource Leveling)
بهینه‌سازی تخصیص منابع پروژه با جابجایی وظایف دارای تداخل منابع. این الگوریتم ابتدا CPM را اجرا می‌کند، سپس در هر بازه زمانی، وظایف با تداخل منابع را شناسایی کرده و وظیفه با اولویت پایین‌تر را به تأخیر می‌اندازد تا تداخل منابع کاهش یابد.

| الگوریتم | ورودی | خروجی | پیچیدگی |
|----------|-------|-------|---------|
| CPM | گراف وظایف + وابستگی‌ها | مسیر بحرانی + شناور هر وظیفه | O(V + E) |
| PERT | تخمین‌های سه‌نقطه‌ای | زمان مورد انتظار + احتمال اتمام | O(V + E) |
| مونت‌کارلو | تخمین‌ها + تعداد تکرار | توزیع احتمال + صدک‌ها | O(N × (V + E)) |
| توپولوژیک | گراف وابستگی | ترتیب خطی وظایف | O(V + E) |
| تراز منابع | گراف + ظرفیت منابع | وظایف جابجا‌شده + تداخلات | O(V² × T) |

## 🤖 هوش مصنوعی

RASK! از مدل **GLM-4.5-flash** (ZhipuAI) به‌عنوان موتور هوش مصنوعی خود استفاده می‌کند. قابلیت‌های AI شامل موارد زیر است:

### برنامه‌ریزی هوشمند مسیر
کاربر هدف پروژه و ترجیحات خود را شرح می‌دهد و AI یک مسیر عملیاتی کامل شامل مراحل، زمان‌بندی و وابستگی‌ها تولید می‌کند. هر مسیر شامل گام‌های قابل‌تعامل با عنوان، توضیحات، مدت‌زمان و اولویت است.

### چت تعاملی
پنل چت هوشمند برای پرسش‌وپاسخ درباره پروژه و دریافت پیشنهاد. کاربر می‌تواند سوالات خود را درباره زمان‌بندی، مدیریت ریسک و بهینه‌سازی مطرح کند.

### پرسش‌های چندگزینه‌ای
سیستم پرسش‌های ساختاریافته برای دریافت اطلاعات دقیق‌تر از کاربر و تولید برنامه‌ریزی شخصی‌سازی‌شده.

### پیشنهاد هوشمند رویداد
در بخش تقویم، AI می‌تواند بر اساس الگوهای استفاده و تقویم شمسی، رویدادهای جدید پیشنهاد دهد.

### حباب‌های بینش (Insight Bubbles)
پیشنهادهای هوشمند و نکات کاربردی که در طول کار با برنامه ظاهر می‌شوند و به کاربر کمک می‌کنند تا از قابلیت‌های مختلف بهره‌مند شود.

### تنظیمات قابل شخصی‌سازی
امکان تغییر مدل AI (GLM-4.5-flash یا GLM-4.5)، تنظیم دما (Temperature) و حداکثر توکن‌ها از طریق دیالوگ تنظیمات هوش مصنوعی.

## 🤝 راهنمای مشارکت

از علاقه‌مندی شما به مشارکت در RASK! سپاسگزاریم. برای مشارکت لطفاً مراحل زیر را دنبال کنید:

1. **فورک** کردن مخزن
2. ایجاد یک **شاخه جدید** (`git checkout -b feature/amazing-feature`)
3. **کامیت** تغییرات (`git commit -m 'Add amazing feature'`)
4. **پوش** به شاخه (`git push origin feature/amazing-feature`)
5. ایجاد یک **Pull Request**

### استانداردهای کدنویسی

- رعایت استاندارد **PEP 8** برای کدهای پایتون
- استفاده از **Type Hints** برای تمام توابع و متدها
- نوشتن **Docstring** فارسی برای تمام کلاس‌ها و توابع عمومی
- رعایت اصول **DDD** و جداسازی لایه‌ها
- نوشتن تست برای قابلیت‌های جدید
